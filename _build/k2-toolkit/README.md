# K-2 SEL Toolkit build kit

Source files for the K-2 SEL Toolkit (resources/k2-behavior-toolkit). Not part of the live site:
GitHub Pages (Jekyll) skips folders that start with an underscore.

- assets/img: curated Lee & Tee x Matchbook art used by the builder
- assets/fonts: Lilita One, Fredoka, Andika (woff2, from @fontsource on npm)
- legacy-set1: the original Gentle Hands scripts (Set 1), kept for reference
- music-video/<topic>: song, Flow clips, and the ffmpeg cut script for each topic video

Tools: Python 3 with playwright (Chromium), pypdf, Pillow; Node with docx 9.x; LibreOffice (soffice) for guide PDFs; ffmpeg; poppler (pdftoppm).
